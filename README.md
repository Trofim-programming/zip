# CODELAB — Онлайн-платформа интерактивного IT-обучения

> Современная образовательная SaaS-платформа с живыми WebRTC-видеозвонками, синхронизированной интерактивной доской, проверкой домашних заданий преподавателем, строгой ролевой моделью и Telegram-ботом.

---

## 🚀 Основные возможности

### 1. Онлайн-занятия и видеоконференции (WebRTC)
- **Двухэтапный сценарий подключения:**
  - **Лобби настройки (`/live`):** предварительная проверка камеры, индикатор уровня звука микрофона в реальном времени (`AudioContext`), выбор аудио/видео устройств, тест динамиков и задание параметров сессии.
  - **Комната звонка (`/live/[roomId]`):** адаптивная сетка видеопотоков, индикаторы речи, демонстрация экрана, встроенный групповой чат и Apple Liquid Glass док-панель управления.
- **Модерация звонка для организатора:**
  - Удалённое отключение микрофона участникам.
  - Глобальное управление правами (разрешение микрофона, камеры, демонстрации экрана).
  - Исключение участников из звонка.
  - Очередь поднятых рук с функцией «Вызвать к доске».

### 2. Совместная интерактивная доска в реальном времени
- **Синхронизация:** открытие доски организатором активирует её у всех участников звонка одновременно.
- **Инструменты:** карандаш, ластик, прямоугольник, круг, выбор толщины и палитры цветов, вставка блоков кода, экспорт снимка в PNG.
- **Управление доступом:** выборочная выдача прав на рисование и защищённый режим демонстрации для зрителей.

### 3. Уроки и домашние задания
- **Панель преподавателя (`/teacher`):**
  - Очередь сданных решений учеников: просмотр кода, выставление оценок (1–5) и текстовых комментариев, принятие работы или возврат на доработку.
  - Конструктор уроков (привязка к курсу, дата, время, учебные материалы).
  - Конструктор домашних заданий с дедлайнами, наградой в XP и шаблоном кода.
- **Кабинет ученика (`/homework`):**
  - Просмотр выданных заданий, дедлайнов и полученных оценок.
  - Встроенный онлайн-редактор кода с подсветкой синтаксиса и отправкой решения в базу данных.

### 4. Ролевая модель и безопасность
- **Administrator:** полный доступ ко всем функциям и системной статистике (строго закреплён за `trofimzivilik14@gmail.com`).
- **Teacher:** доступ к проверке решений, конструкторам уроков/заданий и управлению онлайн-звонками.
- **Student:** обучение, прохождение уроков, сдача заданий, интерактивная доска и участие в конференциях.
- Все проверки прав выполняются на уровне серверных API и базы данных SQLite.

### 5. Telegram-бот (`scripts/bot.mjs`)
- Ролевая адаптивность меню: административные функции для админа, приём решений для учителей, статус заданий и расписание для учеников.
- Использование кастомных премиум эмодзи Telegram в текстах сообщений (`<tg-emoji>`) и inline-кнопках (`icon_custom_emoji_id`).
- Кнопка возврата оформлена строго текстом `◁`.

## 🛠 Стек технологий

- **Фреймворк:** Next.js 16 (App Router, Turbopack)
- **UI & Стили:** React 19, Tailwind CSS v4, Radix UI / shadcn
- **База данных:** SQLite (встроенный модуль `node:sqlite` `DatabaseSync`)
- **Медиа & Сеть:** WebRTC, getUserMedia, getDisplayMedia, Web Audio API
- **Типографика:** Inter + SF Pro стек, JetBrains Mono
- **Интеграция:** Telegram Bot API (Long Polling)
